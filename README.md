## How to run from source
1. Download [Luvit](https://luvit.io/install.html)
2. Make sure it works
3. If theres no deps folder run
```bash
lit install Bilal2453/discordia-interactions
lit install GitSparTV/discordia-slash
```
4. Setup .env
5. Once complete run
```
luvit main.lua
```
Hope that helps!
